# הבניין שלי

אפליקציית ניהול בניין: לוח מודעות, קודי בניין, דיווחי ניקיון ותקלות,
תשלומי ועד בית, ומעלית שבת.

## מבנה
- `index.html` — כל האפליקציה בקובץ אחד
- `sw.js` — service worker; ה-`VERSION` בתוכו מפעיל את באנר העדכון
- `manifest.json`, `icon-*.png` — התקנה למסך הבית
- `netlify.toml` — פריסה ללא בנייה + כותרות מטמון

## שרת
Supabase, פרויקט `my-building` (`rxlmfthgacwmtrkmbcau`).
כל ההרשאות ב-RLS. הזהות היא Anonymous Auth.

## פריסה
כל דחיפה ל-`main` מתפרסמת אוטומטית בנטליפיי.
בווינדוס אפשר פשוט להריץ `update.bat`.

## עדכון גרסה
כששולחים שינוי שהדיירים צריכים לקבל — להעלות את `VERSION` ב-`sw.js`.
בלי זה הדפדפן לא יציג את באנר "עדכון חדש מחכה לך".
